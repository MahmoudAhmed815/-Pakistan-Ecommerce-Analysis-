# Pakistan E-Commerce Data Analysis

## 📌 Project Overview
This project analyzes a Pakistan-based e-commerce dataset to uncover insights into customer behavior, product performance, and revenue trends. The analysis focuses on understanding sales patterns, customer segments, payment behavior, and category performance using both Python and Power BI.

The goal is to transform raw transactional data into actionable insights that support data-driven decision-making.

---

## 🛠️ Tools & Technologies
- **Python**: Pandas, NumPy, Matplotlib, Seaborn, Plotly  
- **Jupyter Notebook**: Data cleaning, EDA, visualizations  
- **Power BI**: Interactive dashboards and KPI analysis  
- **CSV Dataset**: Raw and cleaned e-commerce transaction data  

---

## 🔧 Project Workflow
### **1. Data Cleaning**
- Removed duplicates and irrelevant fields  
- Fixed incorrect data types (dates, numericals, categories)  
- Handled missing values  
- Standardized column names for consistency  

### **2. Exploratory Data Analysis (EDA)**
- Order and revenue trends over time  
- Top-performing product categories  
- Customer purchase frequency and behavior  
- Payment method analysis  
- City and region-level sales breakdown  
- Comparison of product pricing and quantity sold  

### **3. Visualizations**
- Trend charts for revenue and orders  
- Bar charts for category performance  
- Geographic customer distribution  
- Heatmaps for correlation analysis  
- Power BI dashboard for interactive exploration  

---

## 📈 Key Insights
- Identified the highest revenue-generating categories  
- Analyzed seasonal and monthly sales patterns  
- Detected customer purchasing trends and retention patterns  
- Highlighted cities with the strongest sales performance  
- Found opportunities for product optimization and marketing strategy
